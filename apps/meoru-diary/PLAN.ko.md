## 컨셉

이 사이트는 다이어리이자 스티커북이다. 사진은 종이에 붙인 스티커처럼 살짝 기울어져 있고, 정렬은
완벽하지 않으며, 여백이 넓다. 끝없는 한 페이지, 가장자리의 책갈피가 목차, 짧은 about이 책을 닫는다.

## 디자인 방향

### 두 가지 스티커 어법

퍼슈트 팬덤 스티커를 조사하면 두 어법이 나온다.

|             | 서구 (US/EU)                                                        | 일본 (ケモノ / シール帳)                                                              |
| ----------- | ------------------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| 컷          | 다이컷, 3 mm 흰 오프셋 테두리(3인치 기준 ≈4%), 라운드 조인          | フレークシール, 2 mm 오프셋, 더 타이트                                                |
| 재질        | 글로시·홀로그램 비닐 흔함, 투니한 그림                              | 매트가 더 흔함, キラキラ(홀로)는 소수의 귀한 것에만                                   |
| 배치        | "정돈된 혼돈": 앵커 스티커 → 바깥으로 채움, 겹침 많음, 가장자리까지 | 다시 떼어 교환해야 하니 거의 겹치지 않음, 페이지를 캐릭터·색으로 테마화               |
| 페이지 문법 | 면을 채운다                                                         | 40–60% 커버리지, 강조색 ≤3, 글자 모양(て・く・ノ・L・O)을 따라 배치, 작은 사실적 캡션 |
| 부착        | 스티커 자체                                                         | 마스킹테이프(15 mm) 모서리, 포토코너, 체키(instax) 프린트                             |

**방향: 페이지 문법은 일본식, 스티커 오브젝트는 서구식.** 미니멀·넓은 여백이라는 브리프는
シール帳/手帳デコ 감성이다. 반면 사진 하나하나는 흰 오프셋 테두리와 살짝 뜬 그림자가 있는 다이컷
스티커로 읽혀야 한다. 퍼슈트 팬덤 스티커가 그렇게 생겼기 때문이다. 페이지는 절제, 오브젝트는 촉감.

### 스티커 변형

기본 하나에 강조 몇 가지. 매니페스트의 `variant` 필드(추가 예정)로 사진마다 고른다.

1. **다이컷(기본):** 둥근 사각 사진 + 3–4% 흰 오프셋 테두리 + 작고 비대칭인 그림자(글로우 아님).
   나중에 알파 마스크가 있으면 사각형 대신 퍼슈트 실루엣을 따라 테두리를 낼 수 있다.
2. **Instax mini:** 세로 사진용. 54:86 프레임, 테두리는 좌우 ≈4.1 mm / 위 7.4 mm / 아래 15.7 mm
   비율. 아래 띠에 캡션.
3. **Instax square:** 1:1 크롭용, 72:86 프레임, 같은 캡션 띠.
4. **마스킹테이프 프린트:** 흰 테두리 프린트에 반투명 테이프 두 조각을 대각 모서리에. 한 조각은 사진
   뒤로. 테이프 색은 챕터 강조색.
5. **홀로 강조:** 뷰포트당 최대 하나. 띠가 불균일한 conic gradient(시안·블루 근처 밝고 레드·오렌지
   근처 어둡게), 느린 드리프트, `overlay` 블렌드, 포인터로 각도.

### 혼합 콘텐츠: 사진, 퍼소나 스티커, 낙서 (탐색 예정)

책이 사진만으로 채워지지는 않는다. 사진 사이사이와 주변에 오너의 퍼소나가 다양한 표정의 일러스트
스티커로 붙어 있고, 페이지에는 다이어리 꾸미기처럼 손으로 그리고 쓴 작은 흔적이 있다. 세 가지 아이템
종류가 있고, 각각 레이아웃 동작이 다르다.

| 종류      | 무엇                                                   | 레이아웃 동작                                                                                                                                     |
| --------- | ------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| `photo`   | 오너가 찍은 퍼슈트 사진                                | 현재의 엇갈린 그리드. 크고 절제된, 페이지의 주 리듬.                                                                                              |
| `sticker` | 퍼소나 일러스트: 표정 시트, 포즈, 치비, 가끔 홀로      | 작음(사진 셀의 1/3 정도). 그리드의 빈틈에 앉거나 서구식 "peeking"으로 사진 가장자리에 살짝 겹침. 실루엣 다이컷 + 흰 오프셋 테두리, 알파 PNG/WebP. |
| `doodle`  | 손글씨, 화살표, 밑줄, 스탬프, 테이프, 작은 미디어 에셋 | 사진·챕터 제목·페이지 여백에 앵커된 자유 배치 장식. 필수 정보는 절대 담지 않음. 순수 장식이므로 `aria-hidden`.                                    |

풀어야 할 것:

- **매니페스트 형태.** 모든 항목에 `kind` 추가. 사진은 현재 필드 유지. 스티커는 `mask`(알파 에셋)와
  `anchor`(붙는 사진 또는 빈틈). 낙서는 `anchor`, `offset`, `asset`(SVG 또는 이미지). `photos.json`에
  섞는 것보다 별도 `content/stickers.json`이 깔끔할 수 있다. 첫 스티커 세트가 생기면 결정.
- **배치 규칙.** 일본식 페이지 문법 유지: 커버리지 40–60%, 사진 한 행당 스티커 1–2개, 낙서는 드물게.
  스티커는 사진보다 넓은 기울기(±5–8°)로 캐주얼하게. 챕터별 고정 시드로 어느 빈틈을 채울지 결정.
- **표정 스티커를 시스템으로.** 8–12개 정도의 작은 세트를 챕터 전체에서 재사용, 주변 사진의 무드에 맞춰
  선택. 일부 챕터에만 희귀 "홀로" 변형.
- **손글씨.** 캡션과 낙서는 하나의 손글씨 폰트(i18n 때문에 라틴+한글+일본어 커버리지 필요. 없으면
  마커 스타일 라틴 폰트 + CJK는 시스템 폰트로 폴백). 의미를 담는 낙서 텍스트는 스크린리더용 실제 텍스트가
  함께 있어야 하고, 아니면 장식으로만.
- **로딩.** 스티커와 낙서는 작고 반복되므로 인라인 또는 한 번만 프리로드. 사진을 지연시키면 안 된다.
  fetch 우선순위는 사진이 먼저.
- **저작.** 나중에 admin에 "스티커" 업로드 경로(알파 PNG → 알파 WebP)와 사진·빈틈에 스티커/낙서를
  붙이는 간단한 피커 추가.

미결 질문: 스티커가 사진과 겹치는지(서구식) 빈틈에만 앉는지(일본식); 낙서를 손그림 에셋으로 할지 SVG
라이브러리로 할지; 미니멀 브리프 안에서 이 중 얼마나 살릴지. 결정 전에 한 챕터를 두 방식으로 프로토타입.

### 질감

- 페이지 전체에 종이 그레인: SVG `feTurbulence`, ≈4% 불투명도, 타일.
- 프린트는 종이보다 더 미세한 그레인. 비닐 스티커에는 희미한 대각 광택 줄.
- 그림자는 비대칭(한쪽이 뜬 종이). 말린 모서리는 가끔 하나만, 전부에는 절대 아님.
- 균일한 글로우, 회전하는 홀로, 과한 스큐어모피즘은 피한다. 페이지는 여전히 조용해야 한다.

### 레이아웃과 모션

- 2/3/4컬럼 엇갈린 그리드, row gap 18–22vh (구현됨).
- 기울기 ±2–3°, 뷰포트당 ±5° 강조 하나. hover 시 0°로 펴기는 선택. `prefers-reduced-motion` 준수.
- "페이지"당 사진 면적 40–60% 상한. 여백이 콘텐츠다.
- 챕터 = 캐릭터·색·이벤트로 테마화된 페이지. 챕터 라벨이 유일한 제목.

### 타이포와 색

- 종이 `oklch(0.967 0.004 84)`, 잉크는 거의 검정. 챕터마다 마스킹테이프·사진 팔레트에서 강조색 최대 3개.
- 라벨: 작은 대문자 트래킹(현재). 캡션은 手帳デコ 문법: 날짜·장소·날씨, 가는 손글씨 계열 폰트.
  폰트는 미정(레퍼 사이트는 굵고 좁은 grotesque 하나를 쓰지만 이 무드는 아니다).

### 내비게이션

- 우측 가장자리 책갈피 리본(데스크톱 세로 텍스트, 모바일 스트립). 활성 리본에 챕터 강조색을 주어
  마스킹테이프 탭처럼 보이게 하는 것을 검토.
- 선택: 퍼슈터 크레딧을 キャラ名刺/콘배지 카드(3.5×2인치 비율, 클립 구멍, 광택 줄)로 hover나
  상세 뷰에서 보여주기.

## 무료 티어 이미지 인프라

리서치는 R2 + Cloudflare Image Transformations를 추천했지만 무료 플랜은 월 5,000 고유 변환에서
멈춘다. 무료 경로는:

1. **업로드 시 변형을 미리 생성**: sharp로 AVIF + WebP를 384/640/828/1080/1280/1600에 만들고
   20px 블러·대표색까지 뽑아 public R2 버킷에 저장. 런타임 변환 없음 → 쿼터 없음.
2. **로더가 width → 미리 만든 파일**(`<key>/w1080.avif`)로 매핑. `lib/image-loader.ts`에 이 모드를
   추가. `format=auto` 대신 `next/image` formats 협상 또는 AVIF+WebP 폴백 키로 대체.
3. **매니페스트**는 당장은 리포(`content/photos.json`). admin이 생기면 private 버킷으로 옮기고
   사이트는 빌드 타임 또는 ISR로 읽는다.
4. R2 무료: 10 GB 저장, 월 1천만 읽기, egress 0. 이 규모에 충분.

## Admin 업로드 페이지 (나중)

`mumak-www/apps/admin`에서 가져올 것:

- 별도 Vercel 프로젝트·별도 앱(`apps/meoru-admin`). 공개 사이트에는 쓰기 경로가 없게.
- 브라우저는 private staging 키의 presigned PUT을 받는다(Vercel 함수 본문 4.5 MB 제한 → R2 직접 업로드 필수).
- 서버: JPEG 검증, EXIF 회전, 변형 생성, public 버킷에 `Cache-Control: public, max-age=31536000, immutable`로
  기록, 매니페스트 갱신, 사이트 revalidate.
- 토큰 digest 로그인 + 서명된 세션 쿠키. 운영 크리덴셜은 Vercel에만, Git에는 절대 없음. 일일 업로드 상한.
- 사진별 필드: chapter, alt, caption(날짜·장소·날씨), variant, 강조색(선택).
